# Lily Device Platform V0.5.1 - Compatibility and registration fixes

This maintenance rebuild keeps the V0.5 Smart Home Core architecture and fixes the development issues found during first-run testing.

## Changes

- Updated Python dependency ranges for Python 3.14 compatibility.
- Updated Psycopg binary requirement to `>=3.3.0,<3.4`.
- Updated Pydantic/Pydantic Settings to `>=2.12,<3`.
- Removed the unnecessary `uvicorn[standard]` extra to avoid optional binary-wheel friction on very new Python versions.
- Added localhost/127.0.0.1 CORS regex support for Flutter Web random development ports.
- Improved Flutter API handling for FastAPI `422` validation responses.
- Added client-side email and 8-character registration-password validation.
- Registration errors are now retained in `AppState.error` consistently.

## Recommended backend setup on Windows

```powershell
cd backend
C:\Python314\python.exe -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

For Flutter Web, the backend accepts localhost development origins on dynamic ports. Production deployments should set explicit values in `CORS_ORIGINS`.

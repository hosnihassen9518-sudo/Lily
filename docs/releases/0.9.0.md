# Lily 0.9.0

Adds feature-level RBAC, fixed/custom portal and API roles, delegated grant ceilings,
revocable permission-snapshot sessions, portal-managed API credentials, shared rate limits,
auditing and production HTTPS enforcement. The portal includes roles, users/administrators,
API access, sessions, audit and rate settings. The five-pixel GPIO18 LED-strip firmware/model
is included as a separate build; no new mobile binary is required for RBAC compatibility.

Before deployment, read ../access-control.md and back up the database/config/keys. Upgrade
backend and portal together, configure a trusted HTTPS proxy and verify bootstrap access.
Existing portal sessions require login again. Old mobile sessions may require one login;
paired devices remain paired. No live deployment or administrator change is made by this
release branch. Verification results and review findings are recorded in the execution ledger.

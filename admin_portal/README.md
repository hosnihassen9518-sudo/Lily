# Admin Portal

This folder will contain the administration web UI.

Planned functions:

- Admin authentication
- Dashboard
- Users
- Device inventory
- Add devices
- Disable devices
- View assigned owner
- View online/offline status
- Device telemetry
- Music library
- MP3 upload/delete/enable/disable
- Schedules and troubleshooting views

The portal will consume the backend at:

```text
/api/v1/*
```
